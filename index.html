Marta

Marta is a private, single-household assistant built and run by Nawaf Felemban for his own family. It helps file and organize the family's own documents in their own Google Drive and answers questions about them.

It is not a public service: it has one account owner and is not offered to anyone else. The app requests access to Google Drive only so that it can organize the account owner's own files.
