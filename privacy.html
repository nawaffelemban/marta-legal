Marta: Privacy Policy

Last updated: 6 October 2026

Marta is a private assistant used only by its owner and household.

What it accesses

With the owner's consent, Marta accesses the owner's own documents in their Google account, solely to organize them.

How it is used

Only to provide that function for the owner. The data is not used for advertising.

Sharing

Marta does not sell or share this data with anyone. It may be handled by service providers only as needed to perform the function above, and only on the owner's behalf.

Security and retention

Data is stored securely and kept only as long as needed. The owner can revoke access at any time at myaccount.google.com/permissions.

Google API Services User Data Policy

Marta's use and transfer of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.
